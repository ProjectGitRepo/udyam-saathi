# Udyam Saathi: Demo Script

Before recording, set up the app:

1. Click the **reset** button at the top right of the app.
2. Clear the tour flag in the browser console with `localStorage.removeItem("udyam-saathi:tour-done")`.
3. Use Chrome, and keep the volume on for the read-aloud.

## B. 5-minute live pitch (Demo Day, Indore)

1. **Hook (30 s):** "Raise your hand if a customer has ever paid you late." Then: "There's a law that says they owe you interest at three times the RBI rate. Who's ever claimed it?"
2. **Problem (45 s):** stuck money, missed schemes, no credit. Name the Indore persona.
3. **Live demo (2 min):**
   - Speak in Hindi to Saathi and run the recovery flow.
   - Show the alerts.
   - Show the trust score.
4. **Value (45 s):** the one-minute numbers, and the shift from reacting to preventing.
5. **Business and moat (45 s):** ₹299/month, embedded finance, the payment-behaviour graph.
6. **Ask (15 s):** a pilot with 50 Indore MSMEs through TiE Indore members and industry associations.

## C. Backup plan

- If the mic fails on stage, type the same sentence. The keyword router handles it.
- If the network fails, the app still works with no internet once loaded, since data is in the browser.
- Keep a screen recording of the full flow on the laptop's desktop.
